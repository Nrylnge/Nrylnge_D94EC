# Software Dimmer 软件调暗 — 功能介绍

> 一款常驻托盘的 Windows「软件调暗」工具：不动显示器硬件参数，直接把整个屏幕压暗，
> 最深可以压到几乎全黑。原生 PowerShell + WinForms 实现，绿色免安装。

界面副标题：`Grok Build`

---

## 一、它解决什么问题

- 夜里显示器依然刺眼，系统亮度滑块拉到底还是亮；
- 台式机外接显示器根本没有亮度调节（或不支持 DDC/CI）；
- 笔记本电池模式下会被电源管理「偷偷」降亮度，和手动设置互相打架；
- 想一键切换到某个固定亮度（深夜码字、看片、挂机）。

它的思路很直接：**先把硬件亮度顶到 100%，再用软件把画面压暗。**
这样既拿到最大的可调范围，也避免系统的自动调光和你的手动设置来回拉扯。

---

## 二、三种调暗引擎，自动降级

| 模式 | 原理 | 特点 |
|------|------|------|
| **Mag**（默认） | Windows 放大镜 API（Magnification.dll）的全屏颜色变换 | 覆盖最彻底，连开始菜单、输入法候选框这类浮层也一起压暗 |
| **Gamma** | 直接写显卡伽马表（`SetDeviceGammaRamp`，逐显示器） | 驱动层完成，几乎零开销、延迟最低；部分显卡/驱动会拒绝写入 |
| **遮罩 Overlay** | 一个置顶、鼠标穿透、不抢焦点的黑色窗口铺满整个虚拟桌面 | 兼容性最好，任何机器都能用；靠不透明度压暗 |

程序按 **Mag → Gamma → 遮罩** 的顺序自动降级：首选引擎失效时自动切换，
界面上会诚实地标出实际状态，例如 `模式: Mag→遮罩`。

## 三、功能一览

### 亮度调节
- 0%–100% 滑杆拖拽，实时生效；
- 两档范围：**一般**（10%–100%）与 **极暗**（0%–25%，按钮变橙色警示色）；
- 四个预设按钮 —— 一般档：`18% / 35% / 45% / 100%`；极暗档：`0% / 5% / 10% / 25%`，
  托盘右键菜单里同样带着这四个预设；
- 快捷键：`←`/`↓` 减 5%，`→`/`↑` 加 5%，`1`–`4` 直达预设，`Esc` 收起窗口。

### 硬件亮度锁
- 通过 WMI（`root\wmi → WmiMonitorBrightnessMethods`）把内置屏亮度顶到 100%，
  再用 `powercfg` 把电源方案里的「显示自适应变暗」档位设为 100 并重新激活方案，
  防止笔记本在电池模式下自动压暗；
- 4 秒巡检 + 15 秒节流：被系统改回去就立刻重新锁；
- 外接显示器不支持 WMI 亮度时静默跳过，不影响软件压暗。

### 系统集成
- 常驻系统托盘：双击唤回窗口；右键菜单含 显示窗口 / 四个预设 /
  重新锁定硬件亮度 / 重启 / 退出；托盘提示文字实时显示当前亮度百分比；
- 关闭窗口可「关闭到托盘」或直接退出；窗口可置顶；
- 再次双击图标不会弹「已在运行」的干巴巴提示，而是通过命名管道把
  已经运行的那个窗口叫到前台（约 100–200 ms）；
- 标题栏自带 **重启** 按钮：保存设置 → 释放单实例锁 → 拉起新实例，
  改完脚本不用手动杀进程。

### 状态与持久化
- 设置自动保存到 `%APPDATA%\SoftwareDimmer\settings.json`
  （亮度、窗口尺寸、范围档、引擎、托盘/置顶偏好等）；
- 运行日志写在 `%APPDATA%\SoftwareDimmer\error.log`（自动限制在 512 KB）；
- 退出前会把 Mag / Gamma 复位，不会把桌面留在压暗状态。

## 四、界面

深色「仪表盘」风格：暖黑底 + 橙色强调色（#D65A28），顶部卡片带铆钉装饰；
中间是一块奶白色 LCD 读数面板，大号等宽数字，颜色随亮度变化
（≤35% 暖橙、≤75% 主橙、>75% 绿）；下方是自绘的「滚花旋钮」滑杆与圆角按钮、
自绘拨杆式复选框。

窗口默认 500×520，可自由缩放：变高时控件更舒展，变宽时内容区最大不超过
880 px 并居中，避免最大化后拉成一条「扁片」。DPI 感知为 PerMonitorV2，
混合 DPI 多显示器下遮罩也能完整覆盖每一块屏。

## 五、技术细节（给好奇的工程师）

- **单文件应用**：主程序就是 `SoftwareDimmer.ps1`（约 2000 行），WinForms 手写 UI；
  `SoftwareDimmer.exe` 只是一个 66 KB 的 .NET 启动器，负责用隐藏窗口的
  `powershell.exe` 拉起脚本，避免控制台黑框一闪；`SoftwareDimmer.ico` 是图标美术。
- **性能**：快速拖动滑杆时鼠标事件可以超过 100 次/秒，而 Mag / Gamma 的每次调用
  都是真实的驱动 / DWM 往返。程序把「引擎调用」合并节流到约 50 次/秒（20 ms），
  标签与滑杆重绘不节流，所以视觉上依然跟手；引擎切换时只复位一次另一个引擎，
  不会每帧都清。
- **稳定性**：前台窗口切换、菜单弹出、显示器插拔都会触发「重新压暗」
  （WinEvent 钩子 + DisplaySettingsChanged 事件 + 4 秒兜底巡检），
  并做了 180 ms 合并避免事件风暴；所有回调都 marshal 回 UI 线程执行。
- **退出干净**：托盘图标、遮罩窗口、事件钩子、CIM 会话、后台 powercfg 助手
  都有自己的清理路径，不会留下孤儿进程或残留压暗。

## 六、文件说明

```
scripts\
├─ SoftwareDimmer.exe    ← 双击这个启动（无控制台窗口）
├─ SoftwareDimmer.ps1    ← 主程序（请勿删除 / 移动）
└─ SoftwareDimmer.ico    ← 图标（请勿删除）
```

三个文件必须放在同一个目录里；`settings.json` 与 `error.log` 位于
`%APPDATA%\SoftwareDimmer\`，与程序目录分离，换目录不用重新配置。

## 七、快速上手

1. 双击 `SoftwareDimmer.exe`；
2. 拖滑杆，或按 `1`–`4` 选预设；
3. 觉得还不够暗？点 **范围：一般 → 极暗**，可一路压到 0%；
4. 想让窗口一直飘在最上层，勾选 **窗口置顶**；
5. 平时点 × 收进托盘，需要时双击托盘图标唤回。

## 八、常见问题

**Q：为什么 0% 也不是纯黑？**
设计如此：默认最大压暗强度 `MaxOpacity = 0.88`，保留约 12% 亮度避免彻底看不见。
想更黑可编辑 `settings.json` 里的 `MaxOpacity`（1.0 即纯黑遮罩，慎用）。

**Q：外接显示器调不暗 / 没有硬件锁？**
办公显示器通常没有 WMI 亮度接口，程序会静默跳过硬件锁，只用软件引擎压暗，
因此在高亮场景下仍可能不如「硬件调光」那样绝对暗，但夜间使用足够。

**Q：托盘为什么有「重新锁定硬件亮度」？**
部分机型在插拔电源、休眠唤醒后会把亮度改回去；这里的按钮用于立即强制重锁
（日常 4 秒巡检/15 秒节流也会自动处理）。

**Q：关了窗口程序还在跑？**
勾选了「关闭到托盘」就会常驻托盘；想彻底退出请用托盘菜单的「退出」。

**Q：改了脚本怎么生效？**
点标题栏的 **重启** 按钮即可。

**Q：强制结束进程有没有副作用？**
建议正常退出：退出路径会复位 Mag / Gamma。若用任务管理器强杀，
画面可能停留在压暗状态——重新运行一次并正常退出即可复位。
